# Linear Regression – Diabetes Dataset

## Project Overview
An end-to-end Machine Learning project implementing and evaluating Linear Regression models using the Scikit-learn Diabetes Dataset.

## Models Implemented
- Ordinary Least Squares (OLS)
- Ridge Regression
- Lasso Regression
- ElasticNet Regression

## Concepts Covered
- Exploratory Data Analysis (EDA)
- Correlation Heatmap
- Feature Scaling using StandardScaler
- Bias–Variance Tradeoff
- Regularization
- Multicollinearity and VIF
- Linear Regression Assumption Checking
- 5-Fold Cross-Validation
- Model Comparison and Evaluation

## Technologies Used
Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, Statsmodels and Jupyter Notebook.

## Best Model
Lasso Regression achieved a test R² score of approximately 0.4555 on the selected train-test split.

## Project Files
- `Linear_Regression_Diabetes_Project.ipynb` – Complete implementation
- `diabetes_dataset.csv` – Dataset
- `correlation_heatmap.png` – Feature correlation visualization
- `linear_regression_results.json` – Model evaluation results

## Conclusion
This project demonstrates the implementation, evaluation and comparison of OLS, Ridge, Lasso and ElasticNet regression models, along with diagnostic analysis and cross-validation.
